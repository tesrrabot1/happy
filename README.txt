СЕМЕЙНАЯ ПОЗДРАВИТЕЛЬНАЯ ОТКРЫТКА

В проект добавлены все 21 уникальные фотографии, которые были доступны в переписке. Повторно загруженные одинаковые файлы удалены, чтобы не показывать дубликаты.

КАК ЗАПУСТИТЬ
1. Распакуйте архив.
2. При желании положите музыкальный файл assets/music.mp3.
3. Откройте index.html в браузере.

КАК ИЗМЕНИТЬ
Откройте index.html и найдите массив const slides. Для каждого слайда можно изменить photo, alt, title, text и animation.
Фотографии находятся в assets/photo1.jpg ... assets/photo21.jpg. Чтобы заменить фото, сохраните новое изображение под тем же именем.
Поддерживаемые анимации: zoom, left, tilt, parallax, soft.
Музыка: assets/music.mp3. Она запускается только после нажатия на открытку.
\nОбновление: письмо открывается около 3.9 секунды, появляется золотое свечение и сердечко; фотографии имеют мягкий эффект движения; лепестки роз включаются на отдельных слайдах; в финале — персональное поздравление маме.\n
Мобильная адаптация: компактная раскладка для телефонов, учёт безопасных зон iPhone, уменьшенные размеры фото/текста, прокручиваемые точки слайдов и отдельная настройка для альбомной ориентации. На небольших экранах можно прокручивать страницу вниз.


В этой версии использованы 12 новых семейных фотографий, загруженных для обновления открытки.
